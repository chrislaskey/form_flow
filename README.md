# Form Flow

> Batteries included library for creating dynamic form-based user flows in Phoenix.
> Provides a drop-in web UI to build and renderer. Supports stateful multi-form flows.

## Installation

The package can be installed by adding `form_flow` to your list of dependencies
in `mix.exs`:

```elixir
def deps do
  [
    {:form_flow, "~> 0.1.0"}
  ]
end
```

Documentation can be generated with [ExDoc](https://github.com/elixir-lang/ex_doc)
and published on [HexDocs](https://hexdocs.pm). Once published, the docs can
be found at <https://hexdocs.pm/form_flow>.
